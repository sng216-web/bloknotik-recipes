# Оболочка редакции

Маршрут `redakciya/` содержит только общедоступную оболочку и названия полей. Текстов, изображений материалов, QA evidence, ключей и токенов в сборке нет. Маршрут исключён из RSS, sitemap, поиска и Recipe JSON-LD; noindex — инструкция индексации, не механизм авторизации.

На GitHub Pages backend отсутствует. Оболочка остаётся закрытой при недоступном `/api/staging/v1/session`: материал не отображается. Настоящий вход владельца и private deployment ещё не подключены. Рабочее размещение потребует утверждённого HTTPS backend с тем же origin и server-side проверками. Нельзя передавать токены в URL, встраивать контент при build или указывать произвольный backend из query-параметра.

Клиент использует Secure/HttpOnly session cookie, отдельный CSRF token cookie, same-origin fetch и no-store. Сессионный issuer должен проверять identity/membership на сервере; frontend не определяет tenant и роль. Ревизии и права проверяются API на каждом запросе, включая private media. Данные не сохраняются в localStorage. После завершения/истечения сеанса DOM и object URLs очищаются.

Публичный выпуск отключён. Кнопка выпуска disabled; клиент не вызывает release/import/publish API. Отправка на повторную проверку сохраняет только намерение — она не запускает AI.

Сквозной тест SQL/HTTP и mobile screenshots выполняются в private репозитории на явно синтетическом материале. Они не подтверждают production-вход или реальную приёмку редакции. Изменения этой оболочки должны оставаться совместимыми с private reference UI; копировать из private разрешено только три статических UI-файла, без данных или контрактов backend.
