# Изображения

UI использует локальные WebP 1600×1000, полученные из фотографий Unsplash. Это широкоформатные иллюстрации оформления; они не выдаются за фотографии результатов проверенных рецептов. На demo-страницах это прямо указано.

Условия источника: [Unsplash License](https://unsplash.com/license). Исходные фото кадрированы в landscape и оптимизированы в WebP; сайт не делает внешних запросов для их отображения. Логотип и favicon — собственные простые SVG, не содержат внешних ресурсов.

В реальных публикациях изображения должны соответствовать блюду, иметь понятный alt, credit и подтверждённое право использования. Указание rights в JSON не заменяет проверку лицензии. Нельзя использовать временный Notion URL как постоянный публичный адрес. Importer проверяет наличие файлов и реальные размеры; фактическое соответствие блюда фотографии проверяет редактор.
